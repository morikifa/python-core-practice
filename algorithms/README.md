# Алгоритмический тренажёр: Подготовка к экзамену Т-Банка (Осень 2026)

**Дедлайн экзамена:** 06.09.2026 18:00 мск.

---

## Задачи для обязательного решения руками:

1. `task_01_two_pointers.py` — Поиск пары чисел с заданной суммой за $O(n)$ в отсортированном массиве.
2. `task_02_prefix_sums.py` — Префиксные суммы для вычисления суммы любого отрезка за $O(1)$.
3. `task_03_frequency_map.py` — Подсчёт частот элементов через `collections.Counter` и словари за $O(n)$.
4. `task_04_sliding_window.py` — Метод скользящего окна для поиска максимальной суммы подмассива фиксированной длины $K$.
5. `task_05_fast_io_template.py` — Шаблон быстрого потокового ввода `sys.stdin.read().split()` для обхода вердикта Time Limit Exceeded (TLE).
