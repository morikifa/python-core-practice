## 2. Растущие тренды vs Остывающие антипаттерны

### 🔥 Что взлетает (+100% до +2500% YoY):
1. **AI Voice & Real-Time Agents (+2505%):** Голосовые и асинхронные агентные пайплайны.
2. **AI Brand Visibility / LLM SEO (+400%):** Мониторинг упоминаний брендов внутри ответов ChatGPT, Claude, Perplexity (стартап *Peec AI* — $416K MRR).
3. **Automated Verification APIs (+22%):** Быстрые валидационные API телефонных номеров, email, IP (стартап *1Lookup* — $231K MRR).

### ❄️ Что умерло и категорически запрещено делать в портфолио:
1. **Generic Bookmark Managers (-99.9%):** Полный коллапс B2C готовности платить за сохранение закладок.
2. **Generic Chatbots (-95.1%):** Банальные чат-боты без привязки к корпоративным базам данных и транзакционным системам.
3. **Generic Todo / Habit Apps:** Товарная ниша с нулевой добавленной стоимостью. Наш `taskflow-cli-core` ценен исключительно как демонстратор системного POSIX I/O, атомарности и 95% тестов, а не как продукт для конечного пользователя.

## 3. Выводы для линейки проектов портфолио
- **Проект №0 (`taskflow-cli-core`):** Быстро финализировать до 20.09 как фундамент Core Python / POSIX.

- **Проект №3 («Практикум»):** RAG-сервис на базе pgvector с интеграцией LLM API (релевантно тренду Glean/Chatbase).
