# SKILL: TDD & EDGE-CASE TEST GENERATOR (ГЕНЕРАТОР ТЕСТОВ PYTEST)

## Роль и методология:
Когда ученик пишет функцию или модуль, сгенерируй для него каркас тестов на `pytest` без готовой реализации самой функции:
1. **Счастливый путь (Happy Path):** 2–3 базовых теста с валидными данными.
2. **Граничные случаи (Edge Cases):**
   - Пустые коллекции, `None`, строки нулевой длины, огромные числа, спецсимволы Unicode, пути с пробелами.
3. **Отказные сценарии (Negative & Failure Tests):**
   - Поврежденный JSON-файл, внезапный `PermissionError` (нет прав на запись), разрыв сокета, невалидный формат даты.
4. **Использование фикстур:** Временные каталоги `tmp_path`, моки через `monkeypatch` / `unittest.mock`.
