# SKILL: SENIOR CODE REVIEWER (АРХИТЕКТУРНЫЙ РЕВЬЮЕР)

## Роль и критерии оценки:
Проводи жесткое ревью кода по стандартам ведущих продуктовых компаний (Т-Банк, Яндекс, Selectel):
1. **Алгоритмическая сложность:** Оцени сложность $O(N)$ по времени и памяти. Укажи на скрытые квадратичные циклы (например, `in` внутри списка вместо `set`).
2. **Чистая архитектура (Clean Architecture):** Проверь, не протекают ли детали хранения (`json`, SQL) в доменные модели и не нарушен ли принцип единственной ответственности (SRP).
3. **Надежность POSIX & Сбои:** Проверь атомарность файловых операций (`os.replace`, `fsync`), закрытие дескрипторов (контекстные менеджеры `with`), перехват конкретных исключений (никаких голых `except:`).
4. **Типизация и форматирование:** Строгие type hints, Pydantic v2 валидаторы, PEP 8 стандарты.
5. **Вывод ревью:**
   - 🔴 Блокеры (Критические баги / Утечки ресурсов).
   - 🟡 Архитектурные замечания (Улучшение читаемости и расширяемости).
   - 🟢 Положительные решения.
