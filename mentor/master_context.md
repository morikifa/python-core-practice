## 9. ГЛОССАРИЙ СТОЙКИХ ТЕРМИНОВ

1. **Atomic POSIX Write (Атомарная запись на диск)** — метод сохранения данных через запись во временный файл в том же каталоге с принудительным сбросом на физический диск (`os.fsync`) и последующим мгновенным системным переименованием (`Path.replace`), исключающий порчу файла при сбое питания.
2. **`os.fsync(fd)` (Синхронизация дескриптора)** — низкоуровневый системный вызов POSIX, принудительно выталкивающий страницы данных из буфера операционной системы на физический накопитель (SSD/HDD).
3. **`tmp_path`** — встроенная изолированная фикстура фреймворка `pytest`, создающая уникальную временную папку на время теста и удаляющая её после завершения.
4. **List Comprehension (Генератор списка)** — компактная конструкция языка Python для создания списков в одну строку вида `[expr for item in iterable if condition]`.
5. **UUID v4 Prefix Matching** — алгоритм поиска сущности по коротким первым символам уникального идентификатора (например, `a1b2c3d4`) с обязательной проверкой на отсутствие коллизий (*если префикс совпал с 2+ задачами — выбрасывается `ValidationError`*).
6. **Clean Layered Architecture (Чистая многослойная архитектура)** — подход к проектированию ПО, при котором слои изолированы: `models` (бизнес-сущности) $\to$ `storage` (работа с диском) $\to$ `service` (бизнес-логика) $\to$ `cli` (консольный интерфейс).
7. **RAG (Retrieval-Augmented Generation)** — архитектурный паттерн в AI-бэкенде, при котором релевантные факты извлекаются из векторной базы данных (`pgvector`) и передаются в промпт модели для генерации точного ответа без галлюцинаций.
8. **MRR (Monthly Recurring Revenue)** — ежемесячный повторяющийся доход от подписок, ключевой индикатор жизнеспособности SaaS-продукта.
9. **Defensive Programming (Защитное программирование)** — стиль написания кода с явной валидацией типов и инвариантов, предотвращающий попадание невалидных данных в систему.
10. **STAR / XYZ фреймворк** — стандарт формулирования проектных достижений в резюме: *«Достиг [X], измеренного с помощью [Y], сделав [Z]»*.
