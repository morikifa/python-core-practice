# Анализ конкурентов и профилей рынка (Competitors)

**Дата фиксации:** 31.08.2026  
**Контекст рынка:** hh-индекс в IT ~22.9 резюме на вакансию. На каждую junior/trainee вакансию подаётся 40–80 кандидатов. Выделиться можно только за счёт реального качества кода, подтверждённой архитектуры, отсутствия типовых поделок и наличия продакшн-признаков.

---

## 1. Типовой профиль среднего джуна-конкурента (Что делают ВСЕ и почему это НЕ работает)
- **Портфолио:** TODO-list на Django/Flask, Telegram-бот с погодой, калькулятор, клон блога.
- **Инженерные практики:** Отсутствие тестов (0% coverage), отсутствие Docker, один коммит «Initial commit» со всем проектом сразу, захардкоженные токены в коде.
- **GitHub:** Пустой профиль без README, ссылки ведут на `settings/installations`, коммиты отсутствуют месяцами.
- **Позиционирование:** «Ищу работу джуниором, готов учиться всему за еду» (сигнал низкой ценности).

---

## 2. Профиль Матвея (Конкурентное преимущество Middle-Ready)
- **Портфолио:** Проекты со сложной бизнес-логикой (геолокационный маркетплейс PostGIS, RAG-система с векторным поиском).
- **Инженерные практики:** Docker Compose (multi-service), автотесты pytest ≥ 70%, CI/CD на GitHub Actions, логирование, `.env`.
- **GitHub:** Осмысленная история коммитов, ветки с Feature-PR, подробные README с архитектурными схемами.
- **Позиционирование:** Уверенное владение современным стеком (FastAPI, PostgreSQL, Redis, LLM API), понимание архитектуры и готовность решать бизнес-задачи с первого дня.
