# Файлы наставника

Дата канона: **31 августа 2026**. Перед ответом читать `state.md`.

## Как открыть

В VS Code: File → Open Folder → этот репозиторий. Слева папка `mentor/`.

В терминале (WSL):

```bash
cd ~/python-core-practice   # или путь, куда клонирован репозиторий
ls mentor/
less mentor/state.md
code mentor/state.md
```

На GitHub: репозиторий → папка `mentor/` → нужный файл.

Не открывай `github.com/settings/installations/...` как «профиль». Публичный профиль: `https://github.com/ЛОГИН`.
