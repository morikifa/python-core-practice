# Глобальный глоссарий терминов (Glossary)

**Дата создания:** 31.08.2026  
**Правило ведения:** Каждый новый технический термин, упомянутый в ответах или изученный на практике, фиксируется здесь с кратким понятным объяснением, областью применения и датой внесения.

---

| Термин | Простое объяснение (Суть) | Область применения | Дата внесения |
| :--- | :--- | :--- | :---: |
| **Иллюзия компетентности** (Illusion of competence) | Ошибочное ощущение понимания темы после пассивного просмотра видео или чтения кода без самостоятельного написания руками с чистого листа. | Методология обучения | 31.08.2026 |
| **Active Recall** (Активное воспроизведение) | Метод обучения, при котором информация извлекается из памяти самостоятельным решением задач без подглядывания в подсказки. | Методология обучения | 31.08.2026 |
| **Middle-Ready** | Уровень готовности разработчика самостоятельно проектировать, писать, тестировать, упаковывать в контейнеры и защищать архитектурные решения продакшн-уровня. | Карьера / Оценка | 31.08.2026 |
| **Продакшн-признаки** (Production features) | Атрибуты промышленного кода: контейнеризация (Docker), автотесты (pytest), CI/CD пайплайны, логирование, переменные окружения (.env), документация. | Разработка ПО | 31.08.2026 |
| **Накрутка опыта** (Experience packaging) | Рыночная упаковка глубоких pet-проектов и фриланса под коммерческий опыт после достижения реального технического уровня с готовностью детально защитить каждый нюанс на техсобеседовании. | Карьерная стратегия | 31.08.2026 |
| **Traceback** (Трейсбек) | Отчёт интерпретатора об ошибке, показывающий точную цепочку вызовов функций и номер строки, где упала программа. | Отладка в Python | 31.08.2026 |
| **Edge Case** (Крайний случай) | Нестандартная ситуация на граничных значениях входных данных (пустой список, 0, отрицательное число, None, максимальное число), на которой программа может сломаться. | Тестирование / Алгоритмы | 31.08.2026 |
| **Контест** (Contest) | Соревнование по спортивному программированию с автоматической проверкой решений на скрытых тестах по ограничениям времени (TL) и памяти (ML). | Алгоритмы / Отбор | 31.08.2026 |
| **AC / WA** (Accepted / Wrong Answer) | Статусы проверки задачи в тестирующей системе: AC — решение полностью верное, WA — решение выдало неверный ответ на одном из тестов. | Тестирующие системы | 31.08.2026 |
| **Prefix Sum** (Префиксные суммы) | Алгоритмический приём предварительного накопления сумм элементов массива, позволяющий находить сумму любого отрезка за константное время $O(1)$. | Алгоритмы | 31.08.2026 |
| **Two Pointers** (Метод двух указателей) | Алгоритмический паттерн движения двух индексов навстречу друг другу или в одну сторону для обработки массива за линейное время $O(n)$ без вложенных циклов. | Алгоритмы | 31.08.2026 |
| **Code Review** (Ревью кода) | Процесс взаимной проверки исходного кода разработчиками для выявления ошибок, улучшения архитектуры и соблюдения стандартов. | Командная разработка | 31.08.2026 |
| **CI/CD** (Continuous Integration / Continuous Delivery) | Непрерывная интеграция и доставка: автоматический прогон линтеров, тестов и деплоя при каждом пуше в репозиторий. | DevOps | 31.08.2026 |
| **Pull Request (PR)** | Запрос на слияние изменений из отдельной ветки в основную ветку репозитория после прохождения проверок и ревью. | Git / GitHub | 31.08.2026 |
| **Merge vs Rebase** | Merge объединяет ветки с созданием специального коммита слияния, сохраняя историю; Rebase переносит ветку на вершину другой, выпрямляя историю (запрещено делать rebase в публичных ветках). | Git | 31.08.2026 |
| **PAT** (Personal Access Token) | Секретный персональный токен доступа к GitHub API/Git по HTTPS, заменяющий пароль при пуше кода. | Безопасность / Git | 31.08.2026 |
| **.gitignore** | Конфигурационный файл Git со списком файлов и папок, которые никогда не должны попадать в систему контроля версий (секреты, кэш, виртуальные окружения). | Git | 31.08.2026 |
| **venv** (Virtual Environment) | Изолированная программная среда Python с собственным набором пакетов и зависимостей, предотвращающая конфликты версий. | Окружение Python | 31.08.2026 |
| **f-string** (Форматированная строка) | Литерал строки `f"..."`, позволяющий встраивать вычисляемые выражения Python прямо внутрь текста в фигурных скобках `{expr}`. | Python Core | 31.08.2026 |
| **Type Annotations / Typing** | Аннотации типов переменных и сигнатур функций (`def func(a: int) -> list[str]:`), повышающие читаемость и позволяющие находить баги через статические анализаторы. | Python Core | 31.08.2026 |
| **Keyword-Only Arguments** | Параметры функции после символа `*`, которые разрешено передавать исключительно по имени (`def f(*, key=1):`). | Python Core | 31.08.2026 |
| ***args / \*\*kwargs** | Синтаксис упаковки произвольного числа позиционных (`*args` в `tuple`) и именованных (`**kwargs` в `dict`) аргументов функции, а также их распаковки. | Python Core | 31.08.2026 |
| **Tuple Unpacking** (Распаковка кортежа) | Присвоение элементов кортежа или списка отдельным переменным в одной строке (`a, b = b, a` или `first, *rest = items`). | Python Core | 31.08.2026 |
| **Comprehensions** (Генераторы коллекций) | Компактный синтаксис создания списков, словарей и множеств в одну строку через цикл и фильтрацию (`[x**2 for x in nums if x > 0]`). | Python Core | 31.08.2026 |
| **Lambda-функция** | Анонимная однострочная функция без имени (`lambda x: x * 2`), чаще всего используемая как ключ сортировки `sorted(lst, key=lambda ...)` или фильтр. | Python Core | 31.08.2026 |
| **Context Manager (`with`)** | Конструкция языка с методами `__enter__` и `__exit__`, гарантирующая автоматическое освобождение ресурсов (закрытие файлов, соединений с БД) даже при возникновении исключений. | Python Core | 31.08.2026 |
| **Mutable vs Immutable** (Изменяемые и неизменяемые типы) | Изменяемые объекты (`list`, `dict`, `set`) могут менять своё содержимое по ссылке; неизменяемые (`int`, `str`, `tuple`, `frozenset`) при любой модификации создают новый объект. | Python Core | 31.08.2026 |
| **Big O Notation** (Сложность $O(1), O(n), O(n^2)$) | Математическая оценка скорости работы алгоритма или расхода памяти в худшем случае в зависимости от размера входных данных $n$. | Алгоритмы | 31.08.2026 |
| **FastAPI** | Современный высокопроизводительный асинхронный веб-фреймворк для создания REST API на Python с автоматической генерацией Swagger-документации на основе Pydantic. | Backend | 31.08.2026 |
| **hh-индекс** | Соотношение числа активных резюме к числу открытых вакансий; показатель уровня конкуренции на рынке труда (в марте 2026 в ИТ достиг ~22.9). | Аналитика рынка | 31.08.2026 |
