# Стратегия резюме и позиционирования (Resume Track)

**Дата фиксации:** 31.08.2026  
**Принцип формирования:** Формируются 3 независимых резюме под разные сегменты рынка. Инструмент или технология вносятся в резюме только после **2+ недель уверенного практического использования** в коде. Накрутка опыта применяется только после достижения реального уровня компетенций и обязана быть защищаема глубокими техническими деталями на собеседовании.

---

## 1. Резюме №1: Python Backend Developer / AI-Engineer (Основное)
- **Целевая позиция:** Junior+ / Middle Python Backend Developer (к месяцу 10).
- **Ключевой стек (планируемый):** Python 3.12+, FastAPI, PostgreSQL, SQLAlchemy 2.0, Asyncio, Redis, Celery, Docker, Git, Pytest, LangChain / DeepSeek API, pgvector.
- **Текущий подтверждённый стек (31.08.2026):**
  - Python (базовый синтаксис, функции, модули, структуры данных — в процессе закрытия).
  - Git / GitHub (ветвление, слияния, PR, WSL2 окружение).
  - AI-assisted development (NotebookLM, DeepSeek, Continue.dev, Copilot free).
- **Что необходимо доделать до первого отклика:**
  - Закрыть блок Python Core на 100%.
  - Собрать и задеплоить первый production-ready проект.
  - Оформить публичный GitHub профиль.
