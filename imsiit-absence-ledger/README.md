# imsiit-absence-ledger

CLI-журнал пропусков для учёбы в колледже. Не TODO-список.

## Зачем

Считать, по каким предметам копится риск аттестации: дата, пара, предмет, причина, есть ли справка.

## Стек сейчас

Python 3, JSON-файл, стандартная библиотека. Тесты — pytest, когда появятся функции.

## Запуск (когда появится `main.py`)

```bash
python3 -m venv .venv
source .venv/bin/activate
python main.py
```
